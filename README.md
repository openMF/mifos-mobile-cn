# Android Client for Fineract CN

The **Android Client for Fineract CN** is a mobile application built on top of the **Fineract CN platform**.  
It provides a modern Android interface for interacting with core financial services such as authentication, loan management, customer operations, and real-time data access.  
The goal of this project is to help financial institutions extend their services to mobile users through a lightweight and user-friendly interface.

## 📦 Building the Project

Follow these steps to build and run the Android application:

### 1. Install Java Development Kit (JDK)
Download and install the latest version of the **[Java Development Kit (JDK)](https://www.oracle.com/java/technologies/javase-downloads.html)**.

### 2. Install Android Studio
Download the latest version of **[Android Studio](https://developer.android.com/studio)**.  
Ensure that Android SDK components are properly installed.

### 3. Fork and Clone the Repository
Create your own fork of this project, then clone it locally:
